# Загрузка известных данных в RAG

Финансовые операции и отчёты хранятся в PostgreSQL. В RAG загружаются примеры классификации вида «описание → тип → категория» и ваши текстовые правила. Суммы, даты и способы оплаты старых операций не задают значения новых.

## Подготовленный снимок Google Sheets

Лист «Операции» исходной Google-таблицы прочитан без изменений. Локальный снимок находится в `data/import/google-operations.csv`; этот каталог исключён из Git. Текущий снимок содержит 107 строк, из них подготовлены 63 уникальных примера в 15 документах. Файл относится к машине, на которой выполнена выгрузка; после клонирования репозитория на другой машине личные файлы не появятся.

Скрипт требует Python 3.9+ на macOS/Linux и не устанавливает сторонние библиотеки. Поддерживаются CSV с разделителем запятая, точка с запятой или табуляция; заголовок должен содержать «Тип», «Категория», «Описание». Подходит CSV, скачанный из Google Sheets. При обновлении снимка исходную таблицу редактировать не нужно: достаточно её скачать.

Предварительный просмотр (работает без backend и API key):

```sh
python3 scripts/import-rag-history.py data/import/google-operations.csv
```

Результат — `data/import/rag-history.jsonl`, один документ на категорию/тип или несколько частей для большой группы. Каждый пример повторяет свою категорию, чтобы смысл сохранялся после облачного chunking. Одинаковые описания в одной категории объединяются; разные решения сохраняются как разные примеры. Переводы исключаются. Для неполных строк выводятся номера, и загрузка блокируется до проверки; осознанный пропуск возможен через `--allow-skipped`.

Можно открыть подготовленный JSONL локально для проверки. Файлы имеют права `600`; персональные строки и финансовые суммы не выводятся в консоль и не добавляются в Git.

## Загрузить через приложение

1. Создайте OpenAI Vector Store и задайте `OPENAI_API_KEY`, `OPENAI_VECTOR_STORE_ID`, `RAG_ENABLED=true` по [инструкции RAG](../rag/README.md).
2. Подключите PostgreSQL и запустите backend по [инструкции БД](database-setup.md). Для ответов помощника дополнительно нужны `AI_ENABLED=true` и доступная `OPENAI_MODEL`.
3. Выполните из корня проекта:

```sh
python3 scripts/import-rag-history.py data/import/google-operations.csv --upload
```

Команда передаёт подготовленные примеры в OpenAI через `POST /api/knowledge/documents`. Google-документ не изменяется. Для переноса самих операций в PostgreSQL используйте отдельный [разовый скрипт](transactions-import.md).

Статус `in_progress` означает, что OpenAI ещё индексирует материал. Повторите ту же команду позже: она проверит готовность уже отправленных файлов. Только `completed` означает готовность к поиску.

Журнал `data/import/rag-import-state.json` хранит ID файлов и отпечатки отправленных документов с учётом backend и `ragScope` (владелец + Vector Store). Не удаляйте его при обычном повторе команды. Одновременный запуск локальных импортов блокируется файловой блокировкой. Если ответ на отправку потерян, скрипт не отправит документ автоматически снова: сначала проверьте OpenAI Files и журнал, затем вручную разрешите неоднозначную запись. Журнал не гарантирует отсутствие дублей при запуске с другой машины или другим файлом `--state`.

Если backend работает на другом локальном порту, задайте `--api-url http://127.0.0.1:ПОРТ`. Для удалённого backend используйте HTTPS или локальный SSH-туннель. При `--upload` скрипт запросит пароль приложения; логин по умолчанию `vlad13reg`, другой задаётся через `--login`. Cookie сессии и CSRF-токен хранятся только в памяти процесса.

При изменении снимка изменившиеся документы получают новые отпечатки и загружаются как новые. Старые версии автоматически не удаляются: перед обновлением отменённых/исправленных классификаций удалите старые соответствующие файлы в OpenAI, дождитесь обновления поиска и только затем загрузите новую версию. Актуализация индекса по исправлениям — следующий этап.

## Собственные правила и проверка

Небольшие правила можно добавить через форму «Добавить материал» в веб-приложении. Например: «Аренду корта и теннисный инвентарь относить к категории Теннис». Дождитесь сообщения об окончании индексации, затем спросите помощника: «К какой категории относить аренду корта по моим материалам?» Ответ должен опираться на загруженный источник.

Сейчас RAG подключён к помощнику по документам. Автоматическое применение этих примеров в разборе новых транзакций, пользовательские категории в финансовом справочнике и запоминание нажатий в чате ещё требуют реализации. Загрузка примеров сама по себе их не включает.

## Проверки скрипта

```sh
python3 -B -m unittest discover -s scripts/tests -v
```

Тесты проверяют CSV, разделители, объединение примеров, исключение исторических сумм/дат, разделение владельцев/хранилищ и безопасный повтор после сетевого сбоя. Внешние сервисы не вызываются.
